# cmdstash

よく使うコマンドを貯めて、名前で呼び出してクリップボードへ流し込むCLIツール。

## 動かし方（Mac）

```bash
# 1. コンパイル（out フォルダにクラスファイルを出力）
cd cmdstash
find src -name "*.java" > sources.txt
javac -encoding UTF-8 -d out @sources.txt

# 2. 実行
java -cp out cmdstash.Main
```

Eclipse / IntelliJ で使う場合は `src` をソースフォルダに指定し、`cmdstash.Main` を実行するだけで動く。

## はじめて使うとき

メニューの **8. テンプレートから追加する** を選ぶと、AIと考えた実務でよく使う13件が用意されている。
`y` で全件、`n` で番号を指定して1件ずつ追加できる。

```
1) 直前のコミットをやり直す  #git
      $ git commit --amend --no-edit
5) コンテナの中に入る  #docker
      $ docker exec -it {{コンテナ名}} bash
8) ポートを使っているプロセスを探す  #network
      $ lsof -i :{{ポート番号}}
   ...全13件
```

同じタイトルが既にあるものは自動でスキップされるので、あとから何度実行しても二重登録にならない。

## 保存先

```
~/.cmdstash/snippets.tsv
```

タブ区切りのテキストなので、中身は普通のエディタで確認・編集できる。

## 使い方の流れ

```
1. スニペットを登録する
   タイトル > Nginx再起動
   コマンド > docker restart {{container}}
   タグ     > docker
   メモ     > よく忘れるやつ

4. スニペットを使う
   ID > 1
   container > web-1
   → $ docker restart web-1
   → クリップボードにコピーしました。
```

コマンド中に `{{名前}}` と書いておくと、使うときにその値を聞いてくれる。ホスト名やコンテナ名の書き換え忘れを防ぐための仕組み。

## メニュー

| 番号 | 機能 |
|---|---|
| 1 | 登録 |
| 2 | 一覧（よく使う順） |
| 3 | キーワード検索 |
| 4 | 使う（クリップボードへコピー） |
| 5 | 編集（空Enterで変更なし） |
| 6 | 削除（y/n確認あり） |
| 7 | 棚卸しレポート |
| 8 | テンプレートから追加 |
| 0 | 終了 |

ID入力の場面はすべて `0` でキャンセルできる。

## 開発について

- レビュー・実装は、AIアシスタントと対話しながら進めた。
- 実装後に3回のセルフレビューを行い、見つけた不具合として特に「保存に失敗したのにメモリ上のデータが変わったままだった」は、画面表示とデータが食い違う致命的な不具合で、ロールバック処理を入れて実測で確認している。

## 動作環境

- Java 11 以上
- クリップボード連携は macOS 専用（`pbcopy` を使用）。他OSでは画面表示にフォールバックする
